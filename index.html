Synchronisation (GitHub Gist privé)

Partage les données entre ton téléphone et tes autres appareils via un gist secret sur ton compte GitHub. Fusion automatique : rien n’est écrasé, les suppressions sont reportées.

Comment créer le jeton (2 minutes)
  1. Ouvre ce lien en étant connecté à GitHub : créer un jeton « Suivi montagne ».
  2. La note « Suivi montagne » et la case gist sont déjà remplies. Ne coche rien d’autre.
  3. Expiration : choisis « No expiration » (ou une date à 1 an ; il faudra alors refaire un jeton à l’échéance).
  4. Tout en bas, clique sur le bouton vert Generate token.
  5. Copie le jeton (il commence par ghp_). GitHub ne l’affiche qu’une seule fois : garde-le dans ton gestionnaire de mots de passe.
  6. Colle-le ici puis touche Enregistrer et synchroniser. Le premier appareil crée le gist secret suivi-montagne-data.json.
  7. Sur chaque autre appareil : ouvre l’app → Données → colle le même jeton → Enregistrer et synchroniser. Le gist existant est retrouvé et les données fusionnées.

Sécurité : le jeton reste sur l’appareil et n’est envoyé qu’à api.github.com. Il ne donne accès qu’à tes gists et n’est jamais inclus dans les exports. Pour le révoquer : github.com → Settings → Developer settings → Personal access tokens. Un jeton « fine-grained » marche aussi s’il a uniquement la permission « Gists : Read and write ».
